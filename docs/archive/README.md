# Archive

Plans, audits and point-in-time snapshots kept for reference. Nothing here describes
the current code, and none of it is required reading. The living docs are listed in
the repo's `CLAUDE.md`.

- `ROADMAP-*.md` — design passes for features that were never built (or only partly).
- `STATE.md` — what was built as of 2026-08-24 (superseded by the code and `OPEN.md`).
- `TOOLING-EVALUATION.md` — why Playwright, Stylelint, PHPCS and Vitest were adopted.
- `UX-AUDIT-PLAN.md`, `WALKTHROUGH-GUIDE.md` — the screen-by-screen audit plan and checklist.
- `THIRD-PARTY-SKINNING.md` — notes for the shelved admin skin.
