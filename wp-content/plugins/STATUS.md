## (a) What this ecosystem actually is

Own Ur Shit is a self-hosted WordPress plugin ecosystem built as "digital civil service infrastructure" — a musician's business-in-a-box that lets someone opt out of renting their audience, data, and tools from big platforms. One required core (`own-ur-shit`) provides shared services (identity, style tokens, jobs/queue, notifications, debug tooling, event tracking, and now a live visual page/element builder), and a set of peer feature plugins — `bh-streaming`, `bh-contest`, `bh-crm`, `bh-registry`, `bh-monetization-woo`, `bh-courses`, `bh-feedback`, `bh-video`, `bh-live` — each depend only on the core and treat every other peer plugin as optional via `class_exists()` guards. The whole thing runs on ordinary shared hosting (WP-Cron, MySQL, no external services assumed), and the standing architectural discipline is "no vendor lock-in, no quiet dependency on a paid third-party service where an owned equivalent will do." The project owner's current standing priority, restated across nearly every doc, is hardening what exists (core, bh-contest, the style system, bh-crm, Debug Tools) before adding net-new feature surface — though in practice a large amount of net-new infrastructure (the event system, the element/page builder, tier-depth monetization work) has shipped alongside that hardening rather than strictly before it.
